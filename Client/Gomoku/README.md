# Unity 五子棋

Unity 2022.3 LTS 的人机对战五子棋，复用本仓库既有分层：核心规则在 `Assets/Scripts/Core/` 中保持纯 C#（无 Unity 依赖、无随机数、完全确定），Unity 层只负责光标移动、鼠标点击采集、AI 回合驱动与 IMGUI 呈现。打开 `Assets/Scenes/GomokuDemo.unity` 进入 Play 模式即可游玩：方向键或 A/D 移动光标、回车落子，鼠标点击任意空格直接落子（玩家执黑先手），AI 执白用启发式评分立即应答；`R` 键重开一局并保留比分累计；任一方连成五子即胜，六连及以上的长连同样按胜处理（简化规则、无禁手），棋满无胜为平局。

## 结构

- `Assets/Scripts/Core/`：纯规则（棋盘状态机、规则常量与五连扫描、启发式评分 AI、事件日志、对局与比分），`noEngineReferences` 程序集。
- `Assets/Scripts/Unity/`：`GomokuDemoBootstrap`（装配、光标与按键映射、AI 回合驱动）、`GomokuDemoPanel`（IMGUI 木色棋盘、网格线、天元星位、比分、终局提示与事件日志）。
- `Assets/Tests/EditMode/`、`Assets/Tests/PlayMode/`：Unity 测试工程。
- `Core/`、`Tests/`：dotnet 侧纯逻辑工程与 xunit 测试（与 Unity asmdef 并存，源码引用同一批文件）。

## 玩法要素

- 15x15 棋盘，横、纵、两条对角线四个方向连成五子即胜，长连不判禁手直接按胜处理。
- AI 不做全量搜索：候选点限于已有棋子半径 2 邻域内的空格，按「己方成五 100000 > 阻对方成五 50000 > 己方活四/冲四 10000 > 阻对方四 5000 > 己方活三 1000 > 阻对方活三 500 > 其他 1 + 中心偏好」逐档评分，沿四方向数连续子与两端开放性识别棋型；并列最优取行列字典序最小落点，空盘落天元，完全确定。
- 顶部比分累计玩家(黑)胜/AI(白)胜/平局并跨局保留；底部滚动显示最近对局事件（落子、胜负、平局、重开、拒绝），日志封顶 128 条裁剪。
- 终局后棋盘保持终局形状并高亮获胜连线、标记最后落子，按 R 再来一局；非法落点（越界、已占、终局、非玩家回合）由核心直接拒绝并记入事件日志。

## 纯逻辑验证

```powershell
dotnet build Client/Gomoku/Lyking.Gomoku.slnx
dotnet test Client/Gomoku/Tests/Lyking.Gomoku.Core.Tests.csproj
```

测试覆盖五连判定（横/纵/双对角线）、七连长连按胜、占位与越界与终局拒绝、评分函数纯函数确定性、AI 决策确定性与字典序平局决断、即胜手抓取与冲四堵截、多局面落点合法性抽查、比分跨局累计、重开清盘保留比分与事件封顶。15x15 全满构造代价过高，平局路径以「终局后比分正确」覆盖。Unity EditMode/PlayMode 测试需在 Unity 2022.3 LTS 编辑器中运行验证；界面与交互保存真实运行截图。音效、禁手规则、双人本地对战、难度分级与网络对战不在第一版范围内。

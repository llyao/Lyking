# 基准方法

## 固定条件

- Unity：`2022.3.40f1`，先用编辑器再用同一编辑器生成开发构建。
- 实体：默认 10,000 个，可切换 1,000、10,000、50,000。
- 随机：固定种子 `20261003`，初始位置和速度由同一算法生成。
- 更新：每个实体做位置积分，超出 `[-50, 50]` 边界时反弹。
- 采样：跳过前 30 帧预热，之后采样 120 帧；记录最近窗口平均值和峰值。峰值是该窗口内的最大值，不是整个进程生命周期的最大值。

## 读数解释

`更新耗时` 只包住后端的单步更新，不含 UI 和渲染；`帧耗时` 是 `Time.unscaledDeltaTime` 的换算值；`GC 分配` 是当前线程从采样前到采样后的差值。并行 Job 的调度和完成等待属于更新耗时，避免把同步开销隐藏掉。

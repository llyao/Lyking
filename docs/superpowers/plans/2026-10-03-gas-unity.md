# Unity GAS 模拟项目实施计划

> **给代理执行者：** 每个任务按复选框逐步执行；实现阶段使用 `superpowers:subagent-driven-development` 或 `superpowers:executing-plans`，每个任务完成后运行对应验证。

**目标：** 建立一个 Unity 2022.3 LTS 单机演示，用纯 C# 核心模拟能力激活、标签约束、属性修改、Mana 成本、Cooldown 和伤害效果。

**架构：** `Client/GasUnity/Assets/Scripts/Core/` 是不引用 `UnityEngine` 的运行时核心，`Assets/Scripts/Unity/` 只做 MonoBehaviour、输入、UI 和场景装配。核心通过 `AbilitySystemComponent` 接收激活命令并发布确定性事件，表现层只读事件和快照。

**技术栈：** Unity 2022.3 LTS、C#、Unity Test Framework、现有 .NET SDK、xUnit（纯逻辑测试）。

```csharp
[Fact]
public void Fireball_commits_cost_applies_damage_and_blocks_cooldown()
{
    var clock = new ManualGameplayClock();
    var caster = new AbilitySystemComponent(clock);
    var target = new AbilitySystemComponent(clock);
    caster.Attributes.Set("Mana", 100);
    caster.Attributes.Set("AttackPower", 25);
    target.Attributes.Set("Health", 100);
    caster.GrantAbility(FireballAbility.Create(cost: 20, cooldown: 2, damage: 25));

    var first = caster.TryActivate("Fireball", target);
    var second = caster.TryActivate("Fireball", target);

    Assert.True(first.Succeeded);
    Assert.Equal(80, caster.Attributes.Get("Mana"));
    Assert.Equal(75, target.Attributes.Get("Health"));
    Assert.False(second.Succeeded);
    Assert.Equal(80, caster.Attributes.Get("Mana"));
}
```

- [ ] **步骤 3：实现最小 API**：

```csharp
public readonly record struct AbilityActivationResult(bool Succeeded, AbilityFailureReason Reason);
public sealed class AbilitySystemComponent
{
    public AttributeSet Attributes { get; }
    public GameplayTagContainer OwnedTags { get; }
    public event Action<GameplayEvent>? EventPublished;
    public void GrantAbility(GameplayAbility ability);
    public AbilityActivationResult TryActivate(string abilityId, AbilitySystemComponent? target);
    public void AdvanceTime(double seconds);
}
```

`TryActivate` 先完成全部检查，再一次性提交成本和效果；任何检查失败直接返回 `AbilityFailureReason`，不改变属性和冷却。

# 目录说明文档实施计划

> **供执行人员使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施本计划。每个步骤使用复选框跟踪。

**目标：** 为游戏项目的五个一级目录创建简洁的中文说明文档，并提交、推送到远端 `main` 分支。

**实施方式：** 每个目录保留一份独立的 `README.md`，只说明该目录的职责和预计内容。完成后使用文件存在性检查、内容检查和 Git 差异检查验证结果。

**使用工具：** Markdown、PowerShell、Git。

---

### 任务二：验证文档与改动范围

**检查文件：**

- `Art/README.md`
- `Client/README.md`
- `Server/README.md`
- `Share/README.md`
- `Tool/README.md`

- [ ] **步骤一：确认五份文档均已创建**

运行：

```powershell
Test-Path Art/README.md, Client/README.md, Server/README.md, Share/README.md, Tool/README.md
```

预期结果：连续输出五个 `True`。

- [ ] **步骤二：检查文档内容**

运行：

```powershell
Get-Content -Raw -Encoding utf8 Art/README.md, Client/README.md, Server/README.md, Share/README.md, Tool/README.md
```

预期结果：依次输出五份完整的简体中文说明，且没有空文件。

- [ ] **步骤三：检查 Git 差异**

运行：

```powershell
git diff --check
git status --short
```

预期结果：差异检查没有报错，状态仅包含五份新建的目录说明文档。

### 任务三：提交并推送

- [ ] **步骤一：暂存目录说明文档**

运行：

```powershell
git add -- Art/README.md Client/README.md Server/README.md Share/README.md Tool/README.md
```

- [ ] **步骤二：提交改动**

运行：

```powershell
git commit -m "文档：添加各目录说明文档"
```

预期结果：生成一个包含五份目录说明文档的新提交。

- [ ] **步骤三：推送到远端仓库**

运行：

```powershell
git push -u origin main
```

预期结果：远端 `main` 分支创建成功，并包含设计文档、实施计划、隔离工作区忽略规则和五份目录说明文档。

- [ ] **步骤四：确认本地与远端状态**

运行：

```powershell
git status --short --branch
git log -2 --oneline --decorate
```

预期结果：工作区没有未提交改动，本地 `main` 与 `origin/main` 指向相同的最新提交。

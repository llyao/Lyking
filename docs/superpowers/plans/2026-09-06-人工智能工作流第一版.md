## 统一命令与退出码

所有命令从仓库根目录运行：

例如，路由命令使用：

```powershell
dotnet run --project Tool/AiWorkflow/Lyking.AiWorkflow.csproj -- route --text "修改登录协议" --path Share/Protocol/Login.cs
```

固定退出码：

| 退出码 | 含义 |
|---:|---|
| `0` | 命令成功，且没有阻塞问题 |
| `2` | 参数错误或未知命令 |
| `3` | 配置、路径或输入格式错误 |
| `4` | 验证失败或适配漂移 |
| `5` | Git 工作区存在阻塞条件 |
| `10` | 未预期内部错误 |

标准输出只写 JSON，诊断信息写标准错误。这样脚本可以稳定消费结果，人工仍能看到失败原因。

- [ ] **步骤三：实现最小配置模型与加载器**

`WorkflowConfig.cs` 定义以下公开只读模型，JSON 属性名采用驼峰命名策略：

```csharp
namespace Lyking.AiWorkflow.Configuration;

public sealed class WorkflowConfig
{
    public int SchemaVersion { get; init; }
    public required string WorkflowVersion { get; init; }
    public required List<AreaDefinition> Areas { get; init; }
    public required List<RiskRule> RiskRules { get; init; }
    public required Dictionary<string, List<string>> Profiles { get; init; }
    public required ChangeDirectories Changes { get; init; }
    public required AdapterDirectories Adapters { get; init; }
    public required List<string> ExcludedPaths { get; init; }
}

public sealed record AreaDefinition(
    string Name,
    string Root,
    string Context,
    List<string> Keywords);

public sealed record RiskRule(
    string Id,
    string Description,
    List<string> PathPrefixes,
    List<string> PathSegments);

public sealed record ChangeDirectories(string Active, string Archive);

public sealed record AdapterDirectories(
    string ClaudeSkills,
    string CodexAgents,
    string ClaudeAgents,
    string GeminiAgents,
    string Manifest);
```

`WorkflowConfigLoader.Load` 必须使用 `System.Text.Json`，启用大小写不敏感属性匹配和尾逗号支持；它检查版本等于 `1`、五个领域名称和根路径不重复、三个档位均存在，并把所有目录字段交给 `PathPolicy` 校验。错误统一抛出 `WorkflowException`，消息使用简体中文。

`RepositoryLocator.Find` 从 `Path.GetFullPath(startPath)` 逐级向父目录查找 `.lyking-ai.json`，到文件系统根仍未找到时抛出含起点的 `WorkflowException`。

`PathPolicy.ResolveWithinRoot` 先拒绝绝对路径，再用 `Path.GetRelativePath` 验证解析结果不是 `..` 且不以 `..` 加目录分隔符开头。它从根目录逐段检查已经存在的路径，任何组件带 `FileAttributes.ReparsePoint` 都拒绝；只返回规范化绝对路径。

public sealed record RouteRequest(string Text, IReadOnlyList<string> Paths);

`Router.Route` 使用以下确定性规则：

1. 将路径分隔符统一为 `/`，去掉开头的 `./`，拒绝绝对路径和越界路径。
2. 路径位于领域根目录时记 `100` 分并标记为确定匹配；文本每命中一个领域关键词记 `1` 分，只形成候选。

4. 没有路径匹配时，主领域保持空；候选按分数降序、配置顺序升序返回。
5. 风险规则按路径前缀和完整路径段匹配，不用任意子串；涉及三个以上确定领域时追加 `multi-area`。
6. 存在任何风险信号时建议 `controlled`，否则建议 `standard`。工具不自动建议 `direct`，因为用户可见行为和架构选择不能仅靠路径判断。

# GAS 活动效果生命周期设计

本设计的受控变更真源位于 [20261003-gas-unity-active-effects-v1/design.md](../../changes/active/20261003-gas-unity-active-effects-v1/design.md)。

本阶段采用贡献账本模型：活动效果以句柄登记属性加法贡献，属性有效值由基础值与活动贡献重算；效果到期或显式移除时只删除自身贡献。授予标签按活动句柄引用计数，避免多个效果或静态标签互相覆盖。

第一阶段支持持续时间、通过显式无限工厂创建的效果、多属性加法贡献、标签生命周期、目标 ASC 时钟调度、原子回滚和结构化事件；保留 v1 `TryActivate` 火球路径。周期效果、堆叠策略、预测回滚、网络复制、GameplayCue 和生产级 UI 不在本阶段范围内。

# 游戏项目目录说明文档设计

## 目标

为当前游戏项目的五个一级目录补充简洁、明确的中文说明，使协作者无需查看目录内容即可理解各目录的职责。

## 文档范围

在以下目录中分别创建 `README.md`：

- `Art`：说明美术资源及其源文件的存放范围。
- `Client`：说明游戏客户端代码、配置和资源的存放范围。
- `Server`：说明游戏服务端代码、配置和部署文件的存放范围。
- `Share`：说明客户端与服务端共享内容的存放范围。
- `Tool`：说明项目开发、构建和内容生产工具的存放范围。

不创建根目录说明文档，不新增其他项目文件，也不调整现有目录结构。

## 内容结构

每份文档包含：

1. 与目录名称对应的中文标题。
2. 一段简短的目录用途说明。
3. 一组预计存放内容的中文条目。

文档只描述目录职责，不制定尚未确认的技术选型、文件命名规则或协作流程。

## 验证与提交

创建完成后检查五份文档均存在、内容均为简体中文，并确认 Git 改动范围仅包含设计文档和五份目录说明文档。实现提交信息为 `docs: 添加各目录说明文档`，最终推送到远端仓库的 `main` 分支。
